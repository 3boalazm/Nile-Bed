# Nile Bed — المظهر (لايت/دارك) واللوجو

**التاريخ:** 18 أكتوبر 2026 · **النطاق:** دعم الوضع الليلي/النهاري بالكامل + تركيب لوجو الشركة بنسختيه + تجهيز الموقع للنشر على Vercel.

## 1. الشعار

وصل شعار الشركة بنسختين داخل `public/` بأسماء غير صالحة للاستخدام المباشر في الويب (`Gray logo.svg` و`white logo.svg` — مسافة في اسم الملف).

| الملف القديم | الملف الجديد | الاستخدام |
| --- | --- | --- |
| `public/Gray logo.svg` | `public/logo-on-light.svg` | خلفيات فاتحة — كلمة NILEBED بالرمادي الداكن |
| `public/white logo.svg` | `public/logo-on-dark.svg` | خلفيات داكنة — كلمة NILEBED بالرمادي الداكن (#434344)؛ استُخدمت في الدارك مود |

**ملاحظة مهمة:** الشعار "الأبيض" المرفق ليس أبيض فعليًا؛ الكلمة داخله بلون `#434344` (رمادي داكن) بينما الموجة الحمراء متبقية. على خلفية داكنة تبدو الكلمة باهتة/غير مقروءة. لذلك:

- في الترويسة والفوتر (خلفيتان داكنتان دائمًا في الوضعين) يُستخدم ملف **`logo-on-dark.svg`**. نوصي الشركة بتصدير نسخة بيضاء حقيقية من ملف المصدر (AI/PDF) لتُستبدل بنفس الاسم دون أي تغيير في الكود.
- داخل قسم "ESTABLISHED" ذي الخلفية المتغيّرة يُستخدم الملف المناسب للثيم تلقائيًا (`.brand-logo.is-auto`).

أُضيفت أيضًا أيقونة الموقع (favicon) وصور PWA وبطاقة مشاركة 1200×630 (`public/og.png`) مشتقة من الشعار على خلفية الفحم الداكن `#202626`، لأن النسخة السابقة كانت ترسل بطاقة مشاركة بلا صورة.

## 2. الوضع الليلي

- كل الألوان انتقلت إلى **رموز تصميم (tokens)** داخل `styles/nilebed.css`: 93 رمزًا للأسطح والخطوط والنصوص والمعادن في الرسوم التوضيحية، مع كتلة تجاوز كاملة لـ `html[data-theme='dark']`.
- زر تبديل في الترويسة (أيقونة قمر/شمس) بجانب زر اللغة، يوفر `aria-label` و`aria-pressed`.
- الاختيار يُحفظ في `localStorage` تحت `nilebed-theme`، والزيارة الأولى تتبع تفضيل النظام (`prefers-color-scheme`).
- سكربت صغير مضمّن في `<head>` يطبّق الثيم **قبل أول رسم** لمنع وميض الوضع الخطأ (FOUC)، مع `suppressHydrationWarning` على `<html>`.
- `color-scheme` و`theme-color` مضبوطان للثيمين، فحقول النموذج وشريط المتصفح على الموبايل يتلوّنوا صح.

### تباين النصوص

فُحصت أزواج النص/الخلفية في الثيمين حسابيًا (WCAG). أُعدّلت ثلاثة رموز كانت منخفضة في الوضع النهاري:

| الرمز | قبل | بعد | السبب |
| --- | --- | --- | --- |
| `--t-6` (أرقام الأقسام) | `#a5a9a1` | `#8b9089` | 2.27 → 3.09 |
| `--t-placeholder` (نص الحقول الشبح) | `#9a9f99` | `#8a9089` | 2.51 → 3.04 |
| `--mono-accent` (حرف B في المونوجرام) | `#a86d4c` | `#9c6242` | 2.97 → 3.47 |

باقي الأزواج الأساسية (العناوين، الفقرات، أزرار CTA، نصوص الأقسام الداكنة، الفوتر) بين 3.8 و17.4 في الثيمين.

## 3. ما تغيّر تقنيًا

| الملف | التغيير |
| --- | --- |
| `styles/nilebed.css` | إعادة تنظيم كاملة على رموز لون + كتلة دارك مود + شعار ذكي + إصلاحات تباين و RTL |
| `styles/globals.css` | خلفية الصفحة تتبع الثيم، `color-scheme`, حالات focus للحقول |
| `app/page.tsx` | مكوّن `BrandLogo` (نسختان داخل نفس العنصر)، زر الثيم، إزالة أيقونات غير مستخدمة، `<img>` بدل `next/image` لصورة المعرض |
| `app/layout.tsx` | سكربت الثيم قبل الرسم، `theme-color` للثيمين، خطوط عبر `<link>` بدل `@import` (أسرع على Vercel)، `openGraph.images` + `twitter`، `logo` في JSON-LD |
| `next.config.ts` | ملف جديد: `poweredByHeader:false`، رؤوس كاش لأصول العلامة، `allowedDevOrigins` للمعاينة |
| `vercel.json` | تثبيت `framework: nextjs` و`npm ci` و`npm run build` |
| `package.json` | `engines.node: 22.x` |
| `app/manifest.ts` | ملف PWA بالعربية واتجاه RTL وأيقونات |

## 4. ملاحظات للنشر

- **جذر المشروع في Vercel يجب أن يكون جذر الريبو**، وليس مجلد `public/`. الرابط الذي أشار إليه صاحب الطلب هو مجلد الأصول الثابتة فقط، ولو ضُبط كـ Root Directory فلن يبني Next.js أصلًا.
- لا يحتاج البناء أي متغيرات بيئة. `NEXT_PUBLIC_SITE_URL` اختياري لضبط الروابط الأساسية.
- `next build` و`npm run typecheck` يمرّان محليًا على نفس الإصدارات (Next 16.4.2 / React 19.1 / Node 22).

## 5. ما يحتاج تأكيد الشركة

1. تصدير نسخة الشعار البيضاء الحقيقية (من ملف المصدر) لتحل محل الملف الحالي في الدارك مود — نفس اسم `logo-on-dark.svg`.
2. اعتماد النغمة اللونية للدارك مود (أسود فحمي دافئ + نحاسي) بدل الأسود الصافي.
3. صور حقيقية للمصنع/الخامات/خط السوست لتحل محل الرسم التوضيحي.
