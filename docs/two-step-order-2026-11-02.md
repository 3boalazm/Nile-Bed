# طلب من خطوتين: اختيار أولي ← مراجعة وتحديد كميات — 2 نوفمبر 2026

## المطلوب (كما ورد)

1. «راجع الطلب» تبقى **فلوتنج في الشاشة**، مش في آخر الصفحة تحت خالص.
2. اللي أضيفه من الكتالوج **يُضاف فقط**، وما يروحش تلقائي لتحديد الكمية.
3. الكتالوج هو مكان **الاختيار الأولي**؛ الكميات في الخطوة الجاية.
4. يتكتب صراحة في الكتالوج إن ده «اختيار أولي» وإن الكميات في الخطوة الجاية.
5. صفحة تحديد الكميات تعرض **الأصناف اللي اختارها المستخدم فقط**، مش الكتالوج كله.
6. سيستم توكنز واحد + بالِت لايت/دارك + سويتش كامل بلا مشاكل كونتراست
   → موثّق في `docs/design-tokens-2026-11-02.md`.

## الفلو الجديد

```
الخطوة ١  /catalog                الخطوة ٢  /order
─────────────────────────────    ─────────────────────────────────────────
استعراض الـ ٦٩ صنفًا            عرض الأصناف المختارة فقط ( groupings حسب الوحدة )
زر «أضف للطلب» على كل بطاقة  →   حقل كمية (+/−) لكل صنف + ملاحظة اختيارية
   ↳ يسجّل { qty:'', note:'' }      ↳ هنا فقط تُكتب الكمية
   ↳ لا تنقّل، لا كمية تلقائية      ↳ ملخص + بيانات تواصل + إرسال/واتساب/بريد/نسخ
شريط «راجع الطلب» عائم دائمًا      شريط عائم «أضف أصناف من الكتالوج»
```

### ١. الشريط العائم

- في `/catalog` يظهر **دائمًا** (حتى لو العدّاد صفر)، `position: fixed` في أسفل
  الشاشة، ويحتوي: حقيبة + «طلبك الحالي N صنف» + سطر «اختيار أولي — الكميات
  بتتحدد في الخطوة الجاية» + زر برتقالي «راجع الطلب» بسهم اتجاهي حسب RTL/LTR.
  الشكل مقتبس من الصورة المرجعية اللي بعتها صاحب الطلب.
- مُرندَر **كأخ لـ `<main>`** (مش جواه) فمفيش `overflow`/`clip` في أي أب يقدر
  يحبسه؛ `z-index: 900`، و`padding-bottom` على الصفحة عشان ما يغطّيش الفوتر.
- في `/order` نفس الشريط بيعرض «N من M صنف كميتها محددة» + زر الرجوع للكتالوج،
  فالسويتش بين الخطوتين دايمًا قدام عين المستخدم.
- نسخة موبايل مضغوطة، و`prefers-reduced-motion` يلغي الأنيميشن.

### ٢. الاختيار الأولي فقط

- `app/catalog/draft.ts` هو **مصدر الحقيقة المشترك**: `readDraft` / `writeDraft` /
  `togglePicked` / `pickWithoutQuantity` على مفتاح `localStorage`
  `nilebed-order-v1`. الصفحتان تقرآن وتكتبان نفس المسودة، مع مزامنة بين التابز
  عبر حدث `storage`.
- زر البطاقة بقى `<button aria-pressed>` مش رابط `/order?add=...`. الضغطة تضيف
  سطرًا **بكمية فارغة** (`qty: ''`) أو تشيله؛ **لا** `window.location`، **لا**
  `scrollIntoView`، **لا** قيمة `1` افتراضية.
- النسخة القديمة `?add=<id>` لسه مقبولة للتوافق مع الروابط المحفوظة، لكن
  `pickWithoutQuantity` بتسجّل الصنف بكمية فارغة فقط (بدون تحديد كمية/سكرول).
  `?unit=<id>` لسه فلتر عادي.
- نص صريح في الكتالوج: تنبيه «**اختيار أولي**: الزرار بيضيف الصنف لقائمة طلبك
  من غير ما يحدد كمية أو ينقلك لصفحة تانية…» + تعديل `unitsNote` + مؤشر
  «١ الاختيار الأولي ← ٢ مراجعة الطلب وتحديد الكميات» + سطر داخل الشريط العائم،
  بالعربي والإنجليزي.

### ٣. صفحة المراجعة = المختارة فقط

- `picked = items.filter(it => Object.hasOwn(order, it.id))` — أي صنف ما اختيرش
  في الكتالوج **لا يُرندَر أصلًا** (اتأكد من الـ SSR: صفر عنصر `product-*` في HTML
  الصفحة بلا اختيارات).
- الفلاتر والعدّادات وأقسام الوحدات كلها مبنية على `picked` مش على `items`.
- لو مفيش اختيارات → حالة فارغة واضحة فيها زر «أضف أصناف من الكتالوج»،
  والفلاتر تُخفى لأنها بلا معنى.
- كل صف له زر «حذف الصنف من الاختيار» (بيشيل السطر نهائيًا من المسودة).
- **الكمية إلزامية لكل صنف مختار**: الصفوف اللي بلا كمية عليها شارة «الكمية
  مطلوبة»، وملخص الطلب يعرض تنبيه «فيه N صنف لسه من غير كمية…»، وأزرار
  الإرسال/واتساب/البريد/النسخ تبقى معطّلة لحد ما كل الكميات تُملأ. «تفريغ
  الطلب» و«نسخ النص» لسه متاحين بشكل منطقي.
- **ما اتغيّرش**: قواعد الكميات (أعداد صحيحة للقطع، ٠٫٥ للكجم، ٠٫١ للم³،
  الأرقام العربية، الحد الأقصى ٩٩٩٩٩٩)، الرقم المرجعي `NB-YYYYMMDD-XXXX`،
  الاسم/الهاتف المطلوبان، `POST /api/order` + `ORDER_WEBHOOK_URL` الاختياري،
  و`fallback` لواتساب/البريد، وحفظ البيانات في `localStorage` فقط.
- تسمية الصفحة والـ metadata والروابط من الرئيسية بقت «راجع الطلب /
  مراجعة الطلب وتحديد الكميات» بدل «كوّن طلبك / Build an order».

## التحقق

- `npm run typecheck` ✅ · `npm run build` ✅ · `npm run check:contrast` ✅ (٤٦ زوجًا).
- `npm run start` → `/`, `/catalog`, `/order`, `/sitemap.xml`, `/api/order` كلها ٢٠٠.
- HTML السيرفر لـ `/catalog` فيه `nb-float` + «راجع الطلب» + «اختيار أولي»؛
  HTML السيرفر لـ `/order` فيه صفر صفوف `product-*` بلا اختيارات.
- حزمة CSS المبنية تحتوي `--nb-l-bg:#f3f1eb` و`--nb-d-bg:#0f1312` و`--nb-on-hot`.
