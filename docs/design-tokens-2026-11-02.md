# نظام التوكنز / الديزاين سيستم — 2 نوفمبر 2026

**الهدف:** سيستم واحد ثابت يغطي الموقع كله، ببالِت مخصص للّايت وبالِت مخصص للدارك،
وسويتش كامل `data-theme` من غير أي مشكلة كونتراست.

## 1. مصدر الحقيقة الوحيد

`styles/tokens.css` — يُستورد **أولًا** في `app/layout.tsx`.

```
:root                       ← LIGHT palette  (--nb-l-*) + semantic --nb-*
html[data-theme='dark']     ← DARK palette   (--nb-d-*) + نفس الأسماء --nb-*
@media (prefers-color-scheme: dark) :root:not([data-theme])  ← قبل ما السكربت يشتغل
```

- البالِتان كاملتان ومستقلتان: ٦٨ قيمة `--nb-l-*` و٦٨ قيمة `--nb-d-*`
  (أسطح، نصوص، حدود، نحاسي/كورال، حالات، ظلال، ألوان الرسوم المعدنية والفوم،
  وخلفيات الحالات النجاح/التحذير/الخطر اللي جت من PR #13).
- التوكنات الدلالية (`--nb-bg`, `--nb-ink`, `--nb-accent`, …) هي **أسماء فقط**
  بتشاور على قيمة من البالِت: ٨٨ دورًا،منها ٦٨ دورًا معتمدًا على البالِت يُعاد
  تعيينه في بلوك السويتش الواحد (مفيش أي دور ناقص)، والباقي أسماء مستعارة أو
  قيم ثابتة (مسافات، أنصاف أقطار، خطوط) بتتبع السويتش تلقائيًا.
- **توحيد بعد PR #13:** أسماء الأدوار اللي عرّفها `styles/design-tokens.css`
  على `main` (`--nb-brand`, `--nb-brand-hover`, `--nb-ink-muted`, `--nb-line`,
  `--nb-surface-raised`, `--nb-surface-inverse`, `--nb-success-bg`,
  `--nb-warning*`, `--nb-danger-bg`, …) اتنقلت لـ `styles/tokens.css` كأسماء
  مستعارة على نفس البالِت، مع المسافات وأنصاف الأقطار والخطوط. الملف القديم
  اتشال، ومفيش غير ملف توكنز واحد وسويتش واحد لكل الموقع (بما فيه `/order`
  المُعاد بناؤه في PR #12). `app/order/order.css` اتحوّل بالكامل لـ `var(--nb-*)`.
- كل ملفات الـ CSS التانية **مفيهاش أي لون hardcoded** (عدا `#000` داخل
  `mask-image` = ألفا مش لون مرسوم، و`rgba(255,255,255,.0x)` كطبقات شفافة على
  الأسطح الداكنة). تم تحويل ٦٣١ قيمة لون في ملفات الموقع القديمة + ١٦٥ قيمة في
  `app/order/order.css` اللي جت من `main` إلى `var(--nb-*)`.
- العائلات القديمة (`--paper`, `--ink`, `--copper`, `--od-*`, `--t-*`, `--audit-*`,
  `--page`, `--ink-clean`, …) بقت **أسماء مستعارة (aliases)** للتوكنات الجديدة في
  `styles/nilebed.css`, `styles/nilebed-refresh.css`, `styles/audit-refinement.css`.
  أي كومبوننت قديم يتبدّل تلقائيًا مع السويتش من غير تعديل.
- `styles/contrast.css` (يُستورد **أخيرًا**) يثبّت الأزواج المقترنة على الأزرار
  المصمتة: النص على الكورال ≠ النص على النحاسي ≠ النص على أخضر واتساب.
- `app/layout.tsx` → `theme-color` قيم حرفية (الميتاداتا لا تحلّل CSS vars) وهي
  مطابقة لـ `--nb-l-bg` / `--nb-d-bg`؛ أي تعديل للبالِت يلزمه تعديلها.

### السويتش نفسه

السكربت المضمّن في `<head>` (`nilebed-theme-v3`) بيحط `data-theme` قبل أول رسم،
وزر القمر/الشمس في الترويسات الثلاث (الرئيسية / الكتالوج / الطلب) بيبدّله ويحفظه.
`color-scheme` بيتغير مع البالِت فحقول النماذج وشريط المتصفح يتلوّنوا صح.
مفيش بلوك دارك مستقل لأي كومبوننت بيعرّف ألوان — البلوك الوحيد هو بلوك التوكنز.

## 3. بوابة الكونتراست (محسوبة مش تقديرية)

```
npm run check:contrast      # node scripts/check-design-tokens.mjs
```

السكربت يقرأ البالِتين من `styles/tokens.css` ويحسب WCAG 2.1 لكل زوج نص/خلفية
مُ documented. لو أي زوج نزل عن ٤٫٥:١ السكربت يخرج بـ exit code غير صفري،
يعني أي تعديل لون لاحق مش هيمرّر مشكلة كونتراست بصمت.

النتيجة الحالية: **٤٦ زوجًا (٢٣ × بالِتين) كلها PASS**، أقل قيمة ٤٫٦١:١
(`--nb-on-accent` على النحاسي في اللايت) وأعلى ١٧٫٨٠:١. من أمثلة الأزواج
اللي اتصلّحت في الشغل ده:

| الزوج | قبل | بعد |
| --- | --- | --- |
| نص زر الكورال / خلفيته (لايت) | ٣٫٦٣:١ (`#e95431` + أبيض) | ٤٫٨٧:١ |
| نص زر الكورال / خلفيته (دارك) | أبيض على برتقالي فاتح ≈ ٢٫٤:١ | ٧٫٥٠:١ (حبر داكن) |
| نص على أخضر واتساب | ١٫٩٨:١ (أبيض) | ٨٫٠٦:١ (حبر داكن) |
| `--nb-hot-strong` على الخلفية (لايت) | ٤٫٣١:١ | ٤٫٨٣:١ |
| `--nb-success` على الخلفية (لايت) | ٤٫٤٧:١ | ٤٫٩٦:١ |
| hover الكورال + أبيض | ٤٫٠٨:١ | ٥٫٤٥:١ |
| شارة فاتحة فوق صورة + نص `--nb-ink` | نص فاتح على فاتح في الدارك | `--nb-media` + `--nb-on-media` (١٤٫٩:١) |

## 4. إزاي تضيف لون جديد

1. ضيف `--nb-l-xxx` و`--nb-d-xxx` في `styles/tokens.css`.
2. ضيف `--nb-xxx: var(--nb-l-xxx)` في `:root` و`var(--nb-d-xxx)` في بلوك الدارك
   (وكذلك في بلوك `prefers-color-scheme`).
3. استخدم `var(--nb-xxx)` بس في الكومبوننت — **ما تحطش hex**.
4. لو اللون عليه نص، ضيف الزوج لـ `scripts/check-design-tokens.mjs` وشغّل
   `npm run check:contrast`.
